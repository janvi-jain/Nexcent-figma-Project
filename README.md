# 💻 Nextcent

Nextcent is a modern business landing page developed by converting a **Figma UI design into a functional website** using HTML and CSS. The project focuses on accurately implementing the design layout, typography, sections, and visual styling.

## ✨ Features

* 🎨 Figma-to-HTML/CSS implementation
* 🏠 Modern landing page design
* 🧩 Multiple content sections
* 📱 Responsive layout
* 🖼️ Images and icons integration
* 🎯 Clean and structured UI
* 📐 Flexbox and CSS layout techniques
* 📱 Bootstrap and media queries

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* Media Queries
* Flexbox
* Figma

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/janvi-jain/Nexcent-figma-Project
```

### 2. Navigate to the Project

```bash
cd Nextcent
```

### 3. Open the Project

Open `index.html` directly in your browser or use **Live Server** in VS Code.

## 🎯 Project Purpose

The purpose of this project is to practice converting a **professional Figma design into a real website** while improving skills in HTML structure, CSS styling, Bootstrap, responsive layouts, and media queries.
